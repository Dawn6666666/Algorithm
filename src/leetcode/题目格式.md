# LeetCode 题目代码生成模板

当你需要生成新的 LeetCode 题目 Java 类时，请遵循以下结构化数据提取和代码生成规则。

## 1. 关键字段提取 (Structured Data)

AI 需要从用户提供的题目文本中提取以下关键字段：

*   **`questionId`**: 题号 (格式化为 4 位数字，例如 `0704`)
*   **`englishTitle`**: 题目英文名称 (用于类名，例如 `BinarySearch`)
*   **`description`**: 题目描述文本 (需要转换为 HTML 格式)
*   **`examples`**: 题目示例 (包含输入、输出、解释)
*   **`constraints`**: 题目提示/约束条件
*   **`methodSignature`**: 解题方法的签名 (返回值类型, 方法名, 参数列表)
*   **`testCase`**: 提取示例 1 的输入数据，用于 `main` 方法测试

**用户输入:**
> 题号: 0704

**AI 执行动作:**
1.  读取 `src/leetcode/` 目录确认文件是否存在。
